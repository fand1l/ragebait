# 😡 ragebait

Сатиричний сайт-пародія, що зібрав усе, що бісить користувачів в інтернеті.
Виглядає як кулінарний блог із рецептом «Як зварити яйце», але до рецепта ще
треба дістатися: крізь cookie-банер із 47 перемикачами, таймер «тільки
сьогодні», поп-апи розсилки, рекламу й «Олену з Житомира, яка щойно купила
Premium».

Це пародія: жодних справжніх платежів, cookie, розсилок чи трекерів. Усі форми
несправжні й нічого нікуди не відправляють.

## Запуск

```bash
npm install
npm run dev      # локальний сервер на http://localhost:5173
```

Інші команди:

```bash
npm test         # юніт-тести (Vitest)
npm run lint     # oxlint
npm run build    # перевірка типів і збірка в dist/
```

## Що вже є (v0.1)

- Стаття-рецепт з «історією бабусі» та клікбейт-блоками.
- Cookie-банер на пів екрана: відмовитися можна лише вимкнувши 47 партнерів
  вручну, а кнопка «Вимкнути всі» вмикає всіх назад.
- Банер «ТІЛЬКИ СЬОГОДНІ −90%» з таймером, який на нулі «продовжує акцію».
- Поп-ап розсилки з присоромленням за відмову; повертається до чотирьох разів.
- Липка реклама знизу з мікроскопічним хрестиком.
- Спливашки з фейковими покупками.
- Шкала гніву, статистика страждань і фінальний екран зі справжнім рецептом.
- Аварійний вихід: `Esc` п'ять разів або кнопка 😮‍💨 у шапці вимикають увесь
  хаос. Анімації вимикаються, якщо в системі ввімкнено «зменшити рух».

## Як це влаштовано

```
src/
  engine/       планувальник, стан гри (Zustand), рівні гніву
  annoyances/   дратівники — кожен окремим компонентом
  components/   модалка, шапка, шкала гніву, paywall
  content/      тексти: реклама, «партнери», фейкові покупці
  pages/        стаття та фінальний екран
```

Щоб додати новий дратівник: опишіть його в `src/engine/configs.ts` (коли
з'являється, як часто, скільки гніву додає) і зареєструйте компонент у
`src/annoyances/AnnoyanceLayer.tsx`.

Повний план і наступні етапи — у [PLAN.md](PLAN.md).
